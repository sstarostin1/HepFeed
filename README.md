**Telegram-бот-агент, который собирает свежие публикации по физике элементарных частиц (ФЭЧ) и физике ускорителей (ФУ), обогащает каждую работу контекстом и публикует в канал лаконичные профессиональные заметки на русском языке — без популизма и журналистской воды.**

> **Статус: в разработке.** Фаза 1 MVP замкнута: сбор arXiv → дедупликация → генерация заметок (LLM) → публикация в Telegram; ручная модерация опциональна. Далее по [дорожной карте](docs/CONCEPT.md#12-дорожная-карта): обогащение контекстом, русскоязычные источники, авто-режим. Прогресс — в [Issues](../../issues).

## Зачем

Информация по ФЭЧ/ФУ фрагментирована: arXiv, INSPIRE, журналы, институциональные репозитории — всё существует, но не в одном месте и не в одном формате. Абстракт сам по себе не объясняет контекст: на чём работа основана, какая коллаборация за ней стоит, какие ограничения сняты. Популярные каналы пересказывают искажённо («учёные обнаружили»), а русскоязычный сегмент почти не покрыт.

HepFeed решает задачу **раннего оповещения с профессиональным контекстом**: «вот что вышло, на чём оно стоит, почему это может быть вам интересно». Аудитория — специалисты, поэтому никаких объяснений базовых терминов: если статья про `B → K*ℓℓ` — так и пишем.

## Как работает

```
источники (arXiv, INSPIRE, CDS, RSS журналов, институты)
        ↓
дедупликация (DOI → arXiv ID → title + first author)
        ↓
фильтрация и тегирование (эксперимент, тематика, тип результата)
        ↓
обогащение (INSPIRE-граф, Crossref, веб-поиск, полный текст)
        ↓
генерация заметки (LLM, жёсткий формат, ≤ 4096 символов)
        ↓
модерация оператором → публикация в Telegram
```

Каждая заметка — перевод заголовка, идентификаторы (arXiv / DOI), коллаборация, теги, 3–5 абзацев (контекст → что сделано → значение → честный блок «ограничения»), ссылки. Точный формат закреплён в [CONCEPT.md §5](docs/CONCEPT.md).

## Возможности (scope первой версии)

- **Мониторинг источников по расписанию.** Полный перечень и спецификация — в [docs/SOURCES.md](docs/SOURCES.md): от arXiv API и RSS журналов (PRL, JHEP, PRAB…) до русскоязычных институциональных репозиториев (ОИЯИ, ИФВЭ, ИТЭФ, ФИАН).
- **Дедупликация.** Одна статья = одна заметка, в скольких источниках она ни всплыла.
- **Обогащение контекстом** через INSPIRE-граф, Crossref и веб-поиск; извлечение текста из PDF, включая продвинутый модуль получения полных текстов платных публикаций из альтернативных источников (детали и порядок fallback — в [SOURCES.md §9](docs/SOURCES.md#9-рекомендации-по-реализации)).
- **Генерация заметок на русском** через облачную LLM с жёстким запретом на «додумывание» фактов.
- **Публикация в Telegram** — один или несколько каналов с распределением по тегам.
- **Ручная модерация на старте:** одобрить / отредактировать / отклонить до публикации.

**Что не входит в scope** (по крайней мере пока): TTS и подкасты, персонализация, изображения в постах, чат-бот, веб-интерфейс, мультиязычность — полный список в [CONCEPT.md §3.2](docs/CONCEPT.md#32-не-входит-в-scope).

## Быстрый старт

```bash
git clone https://github.com/sstarostin1/HepFeed.git
cd HepFeed
python -m venv .venv
source .venv/bin/activate             # Linux/macOS; Windows Git Bash: source .venv/Scripts/activate
pip install -e ".[dev]"
pre-commit install                    # сканер секретов на каждый коммит
cp .env.example .env                  # заполните реальные значения
```

Диагностика конфигурации (что видно боту из окружения):

```bash
python -m hepfeed check
```

Опрос arXiv (Фаза 1; дедупликация по DOI → arXiv ID → title + первый автор):

```bash
python -m hepfeed poll-arxiv --hours 24             # обновить хранилище новыми статьями
python -m hepfeed poll-arxiv --hours 72 --dry-run   # посмотреть без записи в хранилище
```

Планировщик (опрос по расписанию; интервал — `ARXIV_POLL_INTERVAL_MINUTES`, по умолчанию 6 часов):

```bash
python -m hepfeed schedule                       # работает до Ctrl+C
python -m hepfeed schedule --interval-minutes 1  # быстрая проверка
```

Генерация заметок для статей без заметки (один вызов LLM на статью; статус обработки хранится в БД — статьи без заметки не теряются, включая неудачные попытки):

```bash
python -m hepfeed generate-notes --limit 5            # создать и сохранить заметки
python -m hepfeed generate-notes --limit 1 --dry-run  # посмотреть без записи в БД
```

Публикация готовых заметок в каналы (роутинг HEP/AP по категориям arXiv; с `PUBLISH_MODERATION=true` заметки сначала уходят оператору с кнопками «Опубликовать / Отклонить», решение можно принять прямо в чате или по ID через CLI):

```bash
python -m hepfeed publish                       # опубликовать готовые заметки
python -m hepfeed publish --dry-run             # без отправки и записи
python -m hepfeed publish --approve 7           # одобрить заметку ID 7 (после модерации)
python -m hepfeed publish --reject 7            # отклонить заметку ID 7
```

Управление ботом — команды в личке у бота (только для `TELEGRAM_MODERATOR_CHAT_ID`):

```text
/status   — состояние конвейера (статьи, заметки, публикации)
/pause    — пауза периодических задач
/resume   — возобновить работу
/run poll | notes | publish — ручной запуск этапа
```

Заметки, отправленные на модерацию, приходят с inline-кнопками
«Опубликовать / Отклонить»: нажатие применяет решение (после публикации кнопки
убираются, статус приходит следующим сообщением). Повторные нажатия и решения
по уже обработанным заметкам игнорируются.

Полный текст статьи подтягивается из HTML-рендеринга arXiv и кэшируется в БД
(`LLM_USE_FULL_TEXT`, `LLM_FULL_TEXT_MAX_CHARS`) — заметки строятся по нему,
а не по абстракту.

Тесты и линтер:

```bash
pytest
ruff check . && ruff format --check .
```

Для будущих модулей обогащения понадобятся extras: `pip install -e ".[pdf,db]"` (PyMuPDF, SQLAlchemy) — состав зависимостей см. в [pyproject.toml](pyproject.toml).

## Структура репозитория

```
docs/              концепция и спецификации (единственный источник истины)
src/hepfeed/       пакет конвейера
  ingestion/       сбор публикаций (arXiv сейчас; INSPIRE, CDS, RSS, институты — далее)
  filtering/       фильтрация и тегирование (отложено: уточняется семантика)
  enrichment/       обогащение: полный текст статей (HTML arXiv); INSPIRE/Crossref далее
  generation/      генерация заметок через LLM + пост-проверки формата
  publishing/      публикация в Telegram, модерация (inline-кнопки в чате оператора)
  logging/         журнал обработки, аналитика и настройка логирования
  pipeline.py      один цикл: скачать → окно свежести → дедуп → сохранить
scheduler.py       периодический запуск задач (APScheduler)
tests/             pytest
```

## Дисклеймер

- Заметки генерируются LLM и проходят модерацию, но фактические ошибки возможны — сверяйтесь с первоисточниками по ссылкам arXiv / DOI / INSPIRE.
- Проект не аффилирован с arXiv, INSPIRE-HEP, CERN или издателями.
- Ответственность за настройку источников и конкретное развёртывание несёт оператор — см. [docs/SECURITY_NOTE.md](docs/SECURITY_NOTE.md).
