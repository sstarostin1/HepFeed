# SECURITY_NOTE.md — секреты и юридические оговорки

## Политика секретов

1. Секреты (токен Telegram, ключи LLM-провайдеров, строки подключения к БД) живут **только** в переменных окружения или в локальном файле `.env`.
2. `.env` исключён из репозитория через `.gitignore`; в репозитории лежит только шаблон `.env.example` — **без значений**.
3. Каждый коммит сканируется pre-commit hook'ом [`gitleaks`](https://github.com/gitleaks/gitleaks) (см. `.pre-commit-config.yaml`). На стороне GitHub вторая линия обороны — **Secret Scanning + Push Protection** (включаются в Settings → Code security).
4. Если секрет всё же попал в коммит:
   - считать его скомпрометированным — немедленная **ротация** у провайдера;
   - вычистить историю (`git filter-repo`) и перезаписать ветку — только пока репозиторий не имеет форков;
   - проверить, не ушли ли токены в issue/PR-обсуждения.

## Отчёты об уязвимостях

Сообщайте об уязвимостях **приватно** — через GitHub Security Advisories («Report a vulnerability») в репозитории проекта, а не через публичные issue.

## Юридические оговорки

1. **Публичные API.** Проект потребляет API третьих сторон (arXiv, INSPIRE-HEP, Crossref, Unpaywall, INIS и др.) в соответствии с их условиями использования и лимитами частоты запросов (спецификация — в [SOURCES.md](SOURCES.md)).
2. **Получение полных текстов.** Для платных публикаций может использоваться fallback на альтернативные (теневые) источники — порядок и приоритеты описаны в [SOURCES.md §9](SOURCES.md#9-рекомендации-по-реализации). Использование таких источников — осознанное решение и **ответственность оператора** конкретного развёртывания; авторы кода не призывают к нарушению авторских прав и не несут ответственности за способ использования проекта.
3. **Контент заметок.** Заметки генерируются LLM на основе собранных данных и проходят модерацию, но фактические ошибки возможны. Первоисточники проверять по приведённым ссылкам (arXiv / DOI / INSPIRE).
4. **Аффилиация.** Проект не связан с arXiv, INSPIRE-HEP, CERN, издательствами или любыми упомянутыми институциями.
