# AGENTS.md — правила работы AI-агентов в этом репозитории

Этот файл — краткая инструкция для AI-ассистентов (OpenCode и др.), работающих с кодовой базой. Подробности — в документации из раздела «Источники истины».

## Источники истины

- **`docs/CONCEPT.md`** — концепция: границы scope (§3), формат заметки (§5), функционал модулей (§6), архитектура и стек (§7), метрики и дорожная карта.
- **`docs/SOURCES.md`** — спецификация всех источников данных: API, лимиты, приоритеты, пайплайн обогащения, матрица покрытия.

Если код противоречит этим документам — **документы главные**; расхождение подсвечивается в PR/issue, а не молча правится.

## Что запрещено

1. **Секреты в репозитории.** Токены Telegram, API-ключи LLM-провайдеров, строки подключения к БД — только через переменные окружения (`.env`, шаблон — `.env.example`). Файл `.env` в `.gitignore`.
2. **Данные в репозитории.** Кэш PDF, выгрузки БД, логи, локальные дампы — не коммитятся (см. `.gitignore`).
3. **Выход за scope** (CONCEPT.md §3.2): нет TTS, веб-интерфейса, чат-бота, мультиязычности, изображений в постах, рекомендаций, научпопа.
4. **Галлюцинации в генерации заметок.** LLM получает только данные, собранные на этапе обогащения; «если данных нет — не выдумывай». Это требование промптов и пост-проверок, а не пожелание (CONCEPT.md §10.2).

## Языки

- Документация, README, промпты генерации заметок, комментарии «для пользователя» — **русский**.
- Код: идентификаторы, commit-сообщения (**Conventional Commits**), docstrings — **английский**.

## Стиль кода (актуален с появлением кода)

- Python 3.11+; линтер и форматтер — **ruff**; type hints обязательны.
- Структура: `src/hepfeed/<модуль>` — модули соответствуют §6 CONCEPT: `ingestion`, `filtering`, `enrichment`, `generation`, `publishing`, `logging`.
- Конфигурация — через переменные окружения / pydantic-settings; никаких хардкодов ключей и URL с токенами.
- Тесты — **pytest**, каталог `tests/`; в приоритете модульные тесты дедупликации и фильтрации.

## Коммиты и ветки

- Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`, `ci:`.
- Ветки: `feat/<кратко>`, `fix/<кратко>`, `docs/<кратко>`, `chore/<кратко>`.
- Один PR — одна логическая тема; детали в [CONTRIBUTING.md](CONTRIBUTING.md).
